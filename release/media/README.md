# Workshop artwork

The three square covers are alternatives. No final cover has been selected:

- `cover-scream.jpg`: a roaring boss with a ruined jaw.
- `cover-stare.jpg`: a boss staring directly at the viewer.
- `cover-emergence.jpg`: a boss forcing its way through the crowd.

The four landscape gallery images follow the feature order in
`../workshop-description.txt`:

1. `01-horde-size.jpg`: SET YOUR HORDE SIZE.
2. `02-horde-composition.jpg`: SHAPE YOUR HORDE.
3. `03-speed-resistance.jpg`: STILL NOT HARD ENOUGH?
4. `04-until-dawn.jpg`: THEY KEEP COMING. HOLD UNTIL DAWN.

The covers have no text. The gallery uses only the approved headlines and,
for speed/resistance, the two feature captions. Settings values and setup
instructions belong in text, not the artwork.

## Add the images

1. Select one of the three cover JPGs in Human Host's upload interface.
2. After the Workshop item exists, open its Steam page as its owner.
3. Open the image/video editor under Owner Controls, commonly labeled
   **Add/Edit Images & Videos**, and upload the four numbered gallery files
   in order. Save changes.
4. Check the item in Human Host: the cover belongs on the right and the
   additional images belong in the left carousel.

The exact Steam editor labels have not been checked in an authenticated owner
session. The game's uploader sets the main preview only. Placing images in the
plugin's `content` folder does not add them to the gallery.

JPEG exports are below 1 MB each to meet Valve's
[additional preview API limit](https://partner.steamgames.com/doc/api/ISteamUGC#AddItemPreviewFile).

## Artwork provenance

Generated with the built-in image tool from the user's approved concepts.
These are promotional concept images, not gameplay screenshots. The JPEGs
preserve the original dimensions and composition, with quality 90 encoding.
The release folder also contains the original PNGs. No game files or developer
footage are bundled with these images.
