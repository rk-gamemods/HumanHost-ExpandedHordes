TO UPDATE THIS RELEASE
1. Open Human Host's Workshop, then Upload Mod.
2. Use Update on the existing Expanded Hordes item. Select the content folder.
3. For description or gallery changes, use Owner controls on the Steam page.
   Add/edit images & videos accepts the four numbered JPGs.

Only select content for the mod upload. It contains the DLL and license.
Use the JPGs for uploads; keep the original PNGs for future use.
The artwork is promotional concept art, not gameplay screenshots.

The original 2.3 MB cover PNG failed during submission. The 318 KB JPG uploaded
successfully. The game limits the mod folder to 100 MiB. Steam's gallery editor
allows up to 8 MB per batch; each supplied JPG is below 1 MB.
